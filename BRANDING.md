# TokenPaw brand

## Identity

- Product: **TokenPaw**
- Descriptor: **Local AI Agent Token Observatory**
- Korean descriptor: **로컬 AI 에이전트 토큰 관제 도구**
- Korean tagline: **토큰이 어디에서 새는지 펫이 알려줘요.**
- English tagline: **See where your agent tokens go.**

## Product promise

TokenPaw helps people move from a large token number to an understandable cause:
**model → project → session → prompt → file/tool/context cause**.

The pet is the approachable entry point. The product itself is an evidence-oriented,
local-first diagnostics tool for AI coding-agent usage.

## Visual direction

- Midnight navy surfaces for a calm observability workspace.
- Cyan trace lines for normal activity and amber for attention states.
- The primary product mark is a paw combined with a token/pulse trace.
- Provider-inspired characters are optional companion skins, not the product logo.

## Asset policy

The four companion character reference images under
`desktop/src/assets/characters/reference/` are approved by the project owner for
distribution with this repository. Provider names and marks identify the data source;
they do not imply endorsement. The TokenPaw mark should remain provider-neutral.

## Naming compatibility

The Python package (`ai-agent-token-control-center`) and CLI command
(`agent-token-monitor`) remain unchanged for now so existing local scripts continue to work.
